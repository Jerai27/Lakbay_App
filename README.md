PROJECT DESCRIPTION:
The Travel Planning and Budgeting App (Lakbay) is a Flutter-based mobile application that simplifies trip planning and group coordination.

It enables users to organize all travel components in one centralized platform, including destinations, schedules, transportation, accommodation, activities, and budgets. 

The app supports real-time collaboration through Firebase when online, allowing team members to work together on shared trip plans. 
Users can assign tasks to members, track expenses automatically, and generate comprehensive PDF summaries in fixed receipt format for documentation and sharing. Offline viewing of cached data is supported; data updates sync automatically when connection is restored.

OBJECTIVES: 
This project aims to develop a functional mobile application that streamlines trip planning and enables seamless collaboration among team members when online. The application provides comprehensive tools for organizing travel details, managing group tasks, and tracking budgets efficiently. 
Using Flutter and Firebase, the app delivers a user-friendly platform that simplifies both individual and group travel planning, with offline viewing support for cached data.

SPECIFIC OBJECTIVES:
Implement complete CRUD functionality for all travel components (travel plans, activities, expenses, members, and tasks) with full data persistence in Firebase.

Enable real-time collaboration when online by allowing multiple team members to simultaneously view and update trip data through Firebase listeners, with automatic conflict resolution using last-write-wins strategy. Offline data viewing is supported through caching; updates sync automatically upon reconnection.

Create a budget tracking module with automatic expense calculation, providing users with real-time visibility into trip spending and category-based expense breakdowns when online.

Develop PDF export functionality in receipt format that generates comprehensive, fixed-template trip summaries including itinerary, members, expenses, and total budget for easy documentation and sharing. No customization of PDF layout or formatting is available.
